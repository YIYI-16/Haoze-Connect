ChineseSimplified.isl is the contributed translation from the
official Inno Setup source tree, tag is-6_7_1:
https://github.com/jrsoftware/issrc/blob/is-6_7_1/Files/Languages/Unofficial/ChineseSimplified.isl

The Inno Setup 6.7.1 installer used by our Windows runner does not ship this
file. Keeping it here makes the Chinese installer independent of machine-local
language files. Original translation credits are retained in the file.
The translation text is preserved; trailing whitespace and line endings were
normalized and a UTF-8 BOM was added for the Windows compiler.
The accompanying LICENSE.txt is copied from the same tag with LF line endings.
